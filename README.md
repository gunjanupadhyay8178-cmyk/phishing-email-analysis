# Phishing Email Analysis

## Task 2 — Analyze a Phishing Email Sample

### Objective

The objective of this task was to identify phishing characteristics in a suspicious email sample.

### Tools Used

- Kali Linux
- Text editor
- Phishing email sample

### What I Analyzed

I examined the email for:

- Sender address
- Subject line
- Suspicious URL
- Urgent language
- Social engineering techniques
- Suspicious requests
- Generic language

### Key Findings

The email contained several phishing indicators:

- Suspicious sender address
- Urgent account-suspension warning
- Suspicious domain
- Use of `0` instead of `o` in `micros0ft`
- Request to click a verification link
- Fear and urgency
- Generic greeting

### Files Included

- `phishing_email_sample.txt` — Sample phishing email used for the analysis
- `phishing_analysis.md` — Detailed analysis and phishing indicators
- `interview_questions.md` — Task 2 interview questions and answers

### Conclusion

The sample demonstrates how phishing emails can use urgency, suspicious domains, and social engineering techniques to encourage users to take unsafe actions.

The safest approach is to avoid clicking suspicious links and independently verify the message through an official source.
